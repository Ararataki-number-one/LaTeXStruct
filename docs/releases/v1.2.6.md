# LaTeXStruct v1.2.6

## 一键生成 AI 审计提交包

- 新增“生成 AI 审计提交包”入口，将一次 OCR、分析、独立审阅或模板转换运行的真实产物整理为可直接上传到 ChatGPT/Codex 的标准 ZIP。
- 自动生成 `00_README_FIRST.md`、短提示词、完整提示词和 `submission_manifest.json`；文件角色以宿主程序记录的 `artifact_role` 为准，不再需要用户手动解释各附件阶段。
- 支持 `ANALYSIS_REVIEW_ONLY`、`OCR_ONLY`、`OCR_ANALYSIS_REVIEW`、`TEMPLATE_CONVERSION` 与 `MULTIFILE_PROJECT` 五种工作流，以及 `SUCCESS`、`UNVERIFIED`、`FAILED`、`PARTIAL`、`CANCELLED` 全部终态。
- 提交包基于不可变项目快照，记录 SHA-256、父子关系、机器验证状态、blocker、模型/版本和实际存在的材料；提示词生成器不能自行把结果提升为 VERIFIED。
- 提供快速诊断、标准审计、完整取证三档；标准包可包含源 PDF、原始/OCR TeX、当前 TeX、真实编译或部分编译 PDF、源码预览、日志、diff、报告、验证与决策记录。
- 严格区分 `COMPILED`、`PARTIAL_COMPILED` 和 `SOURCE_PREVIEW`；源码预览首页明确声明它不是 LaTeX 编译结果。
- 默认清理 API Key、Authorization、Codex/OpenAI/GitHub token 和本机绝对路径；多文件 ZIP 内的常见凭据文件会从审计副本中移除，不修改原工程。
- 按字节 SHA-256 去重，重复文件以 aliases/alias_roles 记录；ZIP 使用临时文件完成后原子落盘，同名提交包不覆盖。
- 当 TeX、PDF、验证记录或用户审阅状态变化时，旧提交包标记为 stale，避免继续把过期材料当作当前结果。

## 前端与接口

- 审阅工作台新增“生成 AI 审计提交包”“复制提交话术”“下载 ZIP”“打开所在文件夹”“重新生成”。
- 新增接口：
  - `POST /api/projects/{pid}/audit-submission`
  - `GET /api/projects/{pid}/audit-submission/latest`
  - `GET /api/projects/{pid}/audit-submission/{submission_id}/download`
- 任务进入终态后自动准备轻量 README、提示词和 manifest；完整 ZIP 仅在用户点击时生成，避免重复压缩大型源 PDF 与证据文件。

现有“导出 TEX”和“导出工程 ZIP”的行为保持不变。
